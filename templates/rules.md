# Rules

One line per correction. Newest first. Every run reads this file before it starts.

Format: `YYYY-MM-DD  <scope, if narrow>  <what to do>`

Say what to do, not only what to avoid. If a rule needs a paragraph, it is really two rules, or it belongs in a skill. Only I add lines here. The assistant may propose one on the morning page.
